## Before you start

- **Order.** Sitting 1 comes first: it takes this PC from 0.24.6 to 0.24.7
  through the in-app updater. The other sittings can run in any order, over
  several days.
- **Ticks.** Tick each box that behaves as its expected result says. If it does
  not, leave the box empty and write one line on what you saw.
- **Hand-backs.** Name each screenshot as its step asks. Log excerpts come from
  `%LOCALAPPDATA%\sc2tools\logs\agent.log`; copy only the lines a step asks for.
  Never send `%LOCALAPPDATA%\sc2tools\agent.json` or the whole folder: it holds
  this PC's device token.
- **Logs.** `agent.log` rotates at 5 MB into `agent.log.1` to `agent.log.3`, and
  each line reads `YYYY-MM-DDTHH:MM:SS LEVEL logger | message`
  (`apps/agent/sc2tools_agent/runner.py:102-104,2328-2350`). Parse workers write
  `agent-worker-<pid>.log`, and every start of the app deletes the old ones
  (`apps/agent/sc2tools_agent/watcher.py:99`;
  `apps/agent/sc2tools_agent/runner.py:2351`), so copy a worker excerpt before
  restarting. Open the folder from tray, More, 'Open log folder'
  (`apps/agent/sc2tools_agent/ui/tray.py:289`); the Activity log page shows the
  tail of `agent.log`.
- **Safety.** Back up the OBS scene collection before Sitting 4. Never use your
  real replay folders as a deletion fixture in Sitting 3. Never induce server
  errors or rate limits in production; those paths stay covered by tests.

## Known issues found while checking the source

These were found in the released source while writing this checklist. Expect
the affected steps to show them, and record what you see.

- **Items 62 and 185.** In 0.24.7, 'Import help' on the import card and 'Help' on Skipped lines open nothing: they ask for the help topic `desktop-app-import`, which the website has but the agent's allowlist omits, so `help_url` raises (`apps/agent/sc2tools_agent/ui/game_dashboard.py:58`, `apps/agent/sc2tools_agent/ui/recent_games.py:313`, `apps/agent/sc2tools_agent/ui/help_links.py:5-10,18-20`). The website's parity test copies the same list (`apps/web/lib/help/__tests__/agentLinks.test.ts:6-21`), so no test catches it. Record it as failed; every other '?' should work.
- **Item 187.** If In-game assistance is off or the Companion snapshot is unhealthy, a card preview does not open and Settings says 'Your current check-in is already open.' (`apps/agent/sc2tools_agent/ui/build_checkin_settings.py:168-170`). Step 187.1 turns In-game assistance on first; if you see that message anyway, record it.
- **Item 17.** The website calls the switch 'Run on Windows startup', while the app labels it 'Run SC2 Tools Agent on Windows startup' (`apps/web/lib/help/articles/desktop-app/desktop-app-install.ts:34`, `apps/agent/sc2tools_agent/ui/gui.py:2188-2189`). Copy only; the behaviour is the same.
- **Item 14.** No log line names the unlink itself: the heartbeat's 401s log at DEBUG (`apps/agent/sc2tools_agent/heartbeat.py:121`), and the socket's INFO lines `socket_client_disconnected` and `socket_client_connected` show only the drop and the reconnect (`apps/agent/sc2tools_agent/socket_client.py:222,232`). Screenshots are the evidence for the unlink.

## What this acceptance cannot establish

- **Signing.** Item 17 here covers the installer's behaviour only. Its signing
  decision and the signed-build criterion stay separate owner steps.
- **Server-side failures.** Server-busy and rate-limit handling stay covered by
  tests; this checklist never induces them.
- **Other machines.** One PC, one account and one OBS install: no fleet,
  browser matrix or second-device proof.
- **Fixes.** A failed step is recorded, not fixed here. A fix ships in a later
  agent release; 0.24.7 is not rebuilt or republished.
