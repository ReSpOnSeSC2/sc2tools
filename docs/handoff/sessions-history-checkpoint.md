## Feature and contract

Private list/report/current reads derive complete sessions from existing owner
replays. Selected membership and local output day/window stay separate;
unknowns bridge membership while W/L, duration, macro and build summaries retain
their sample/provenance cues. Exact-account/queued-race/rating-scope MMR keeps
incomparable tracks raw, gaps visible and full curves independent of point/game
paging. Natural history ignores the latest manual reset; current retains its
fixed live universe and inclusive anchor.

Today current/last/manual-reset states, personal Activity day links, desktop/
More navigation, saved/default Sessions views, removable patch-era membership,
stale/context/size recovery, owner/path retirement and explicit Next-games
focus use the existing application conventions. Loaded-chart intent survives
same-report game paging without old payload retention. A committed reset emits
an owner-room zero-insert refresh through the shared clock. No migration,
index, provider activation, extra infrastructure or agent release is required.
Optional cache flags remain OFF.

See [ADR 0068](../adr/0068-private-session-history.md) for exact bounds,
publication fences and the unresolved physical multikey query limitation.
