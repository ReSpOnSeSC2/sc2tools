# RZ2: Randomizer for every race, with independent build and unit draws

**Shipped (stacked on #999, LV1).** Per matchup, **Draw a build order** and **Draw opening units** are independent switches (config version 3; an older config reads exactly as before). Terran and Zerg draw opening units like the Gateway draw: one, or two for a two-building opener. Units alone: the OBS widget reveals only the units, the desktop loading card shows them under **Randomizer: opening units** and keeps them in the **Locked in** bar; the native randomizer and the channel-point reroll still need the build draw. Settings → Randomizer reads race, then matchup, then the two switches, with an **Opening units** section. Agent 0.26.0 (unchanged), ADR 0109.

**Where the lists come from.** Protoss: its four Gateway units and `inferGatewayCount`, unchanged. Terran and Zerg, per matchup: the units named by that matchup's own pre-made builds (`build-definitions.generated.json` names, read with the icon registry's unit names and short names), kept when `presetCatalog.json` `unitTechPrerequisites` lists one structure; `openingUnitPools.test.ts` re-derives all six and fails on drift. Every Terran and Zerg matchup has units to derive. A new build starts with the units its name names (the whole matchup list when none) and draws two when they come from two structures; custom builds use their names too (the settings list carries no build order). A Terran or Zerg build saved without units uses its matchup's.

**Random.** The agent latches "Random" on `user.race`; the widget and the API read the streamer's own `players[]` row (unique by name) once concrete. Proven by tests (`RandomizerWidget.modes`, `randomizerSwitches`, `nativeRandomizer`). The desktop loading card is never shown for Random games (check-in contract `HIDE_RANDOM` in `controller.py`, 2,546 lines, out of reach under the 800-line rule), so it draws nothing there.

**Decisions.** Units drawn alone start at the game seed's first value (after a build, after its two). A declared build hides a build reveal, never units drawn alone. A reveal part leaves the screen when its own switch turns off. The unit reveal and unit names load on demand (`loadUnitStage`), warmed while games are pending. The Companion's switch is relabelled **Draw a build order**; agents older than 0.26.0 still say "Enable for this matchup", which now turns the build draw alone. The unit frame keeps its 370 px height on narrow screens; odds chips go icon-and-odds past four units and drop names below 480 px; the power-surge sockets span the frame.
