# RZ2: Randomizer for every race, with independent build and unit draws

**Shipped (stacked on #999, LV1).** Per matchup, **Draw a build order** and **Draw opening units** are independent switches (config version 3; an older config reads exactly as before). Terran and Zerg draw opening units like the Gateway draw: one, or two for a two-building opener. Units alone: the OBS widget reveals only the units, the desktop loading card shows them under **Randomizer: opening units** and keeps them in the **Locked in** bar; the native randomizer and the channel-point reroll still need the build draw. Settings → Randomizer reads race, then matchup, then the two switches, with an **Opening units** section that comes first while units are drawn alone. Agent 0.26.0 (unchanged), ADR 0109.

**Where the lists come from.** Protoss: its four Gateway units and `inferGatewayCount`, unchanged. Terran and Zerg, per matchup: the units named by that matchup's own pre-made builds (`build-definitions.generated.json` names, read with the icon registry's unit names and short names), kept when `presetCatalog.json` `unitTechPrerequisites` lists one structure; `openingUnitPools.test.ts` re-derives all six and fails on drift. Every Terran and Zerg matchup has units to derive. A new build starts with the units its name names (the whole matchup list when none) and draws two when they come from two structures. A Terran or Zerg build saved without units uses its matchup's.

**Random.** The agent latches "Random" on `user.race`; the widget and the API read the streamer's own `players[]` row (unique by name) once concrete, proven by tests. The desktop loading card is never shown for Random games (`HIDE_RANDOM` in `controller.py`, 2,546 lines), so it draws nothing there, and the API's automatic desktop roll skips a Random queue (it would save a pick no card shows).

**Decisions.** Units drawn alone start at the game seed's first value (after a build, after its two). A declared build hides a build reveal, never units drawn alone; a saved pick is ignored while the build draw is off. The settings never leave the unit draw on without units: turning it on, or turning the build draw off under it, stores the matchup's defaults; a version-3 unit switch with nothing to draw reads off on the web (the widget and the agent already drew nothing). The matchup's own units card shows only while a draw uses it (never for Protoss with the build draw on). The unit reveal loads on demand, and the stage holds its 370 px frame height from the first act. On narrow screens long decks show icons and odds, sockets drop "circuit", and two-word unit names wrap.
