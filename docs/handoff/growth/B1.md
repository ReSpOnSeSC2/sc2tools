# B1 · Ladder balance snapshot

- **Shipped.** The offline preview accepts normalized ladder counts and emits each non-mirror matchup's sample size, win rate and 95% Wilson interval by league tier. [ADR 0082](../../adr/0082-ladder-balance-snapshot.md) has the command and input contract.
- **Decisions.** Pool disjoint counts across duration buckets before calculating intervals. Keep same-tier and cross-tier counts separate. An empty cohort has a null rate and interval.
- **Verified.** 25/25 focused API tests, API TypeScript, changed-file ESLint, Node syntax and diff checks passed. Ten exact-match mutations failed on the intended assertions. All original source bytes were restored.
- **Preview.** The synthetic Diamond 1 PvT fixture produced 60 wins in 100 same-tier games (95% interval 50.20% to 69.06%) and 3 wins in 50 cross-tier games.
- **Blocked on G2.** Written SC2Pulse agreement and confirmation of cross-tier assignment, null-frame meaning and wins orientation are needed for a real fixture, nightly collection, storage, a cacheable API and the static `/balance` page.
