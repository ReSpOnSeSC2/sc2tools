# X1: normalized page address on every analytics event

**Shipped (PR stacked on 881).** For visitors who accepted analytics, every Google Analytics event reports the normalized page: page views, custom events and the events gtag.js raises itself. The referrer is normalized the same way and untracked surfaces send nothing. The special case in `lib/analytics/shareEvents.ts` (a file 881 adds) is removed.

**Step 1, measured 2026-11-09.** Throwaway local page, gtag.js under the app's `config`, every hit recorded and blocked (CSP `connect-src 'self'`, nothing escaped). Containers: made-up `G-X1PR0BE000` and production `G-Y90FRFK3D7`. Loaded at `/app/opponents/SECRETLOAD?tab=y&q=SECRETQ0` from `/app/game/SECRETREF?tab=z`, then `pushState` to `/app/game/SECRETPUSH?tab=x&q=SECRETPUSHQ`.

| Event | `dl` before | `dl` after |
|---|---|---|
| `page_view` with a location | `/app/opponents/:pulseId` | same |
| custom event without one | `/app/opponents/SECRETLOAD?tab=y&q=SECRETQ0` | `/app/opponents/:pulseId` |
| `user_engagement`, `click`, `file_download`, `form_start`, `form_submit` | raw, as above | `/app/opponents/:pulseId` |
| `user_engagement` after `pushState`, before the app's page view | `/app/game/SECRETPUSH?tab=x&q=SECRETPUSHQ` | `/app/opponents/:pulseId` |
| custom event after the next `page_view` | `/app/game/SECRETPUSH?tab=x&q=SECRETPUSHQ` | `/app/game/:gameId` |
| `view_search_results`, raised at `config` | raw | normalized only with the state set before `config` |
| anything on `/overlay/SECRETTOKEN`, `/admin/SECRETADMIN` | raw | not sent |

- `dr` rode on every event: `/app/game/SECRETREF?tab=z` before, `/app/game/:gameId` after; an untracked referrer becomes the site root.
- **Decisions (ADR 0076).** Page state set before `config` (from the router, not the browser's address) and on every navigation; `gaEvent` states its own page; referrer included although the block named only `dl`; untracked pages raise Google's opt-out flag, composed with consent in one function.
- **Verification.** Web suite 10,953 passed and 1 skipped (1,107 files) before the review fix; the 9 analytics and shell files (165 tests) pass after it. Mutations 10/10 killed. `tsc`, `eslint` on the changed files and ui-lint clean; `next build` passes. In a browser, on the built app with a made-up measurement id: state set before `config`, normalized `dl` on page views and on `user_engagement` after a client-side move, 0 hits on `/overlay/<token>`, `dr` cut to the site root after leaving it. One independent review, 7 findings: 1 code defect fixed (the init script read the address being left), 4 wording fixes, 2 older consent gaps kept as follow-ups.
- **Owner action.** Two GA "enhanced measurement" options read the browser's address themselves (measured, production container): `form_start`/`form_submit` send `form_destination`, the raw page address for a form without `action`; `view_search_results` sends `search_term` from `q|s|search|query|keyword` at page load (the opponent list search is `?q=`). Switch off **Form interactions** and **Site search**: GA Admin, Data streams, web stream, Enhanced measurement.
- **Not verified.** GA's `scroll` event never fired in the probe, so its `dl` was not observed. Signed-in pages were not opened in a browser.
- **Follow-ups.** Page titles (`dt`) are not normalized: a community opponent page's title has its Pulse id, a public player page's the display name, a build page's the build name. A consent change made in another tab is not heard on `/status`, and a cross-tab re-grant never sends gtag `consent update` (both predate this slice). Ledger: none.
