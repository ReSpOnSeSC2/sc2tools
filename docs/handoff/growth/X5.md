# X5: fixed page titles in analytics

**Shipped.** Record routes report their fixed route template as `page_title`. Other tracked routes report `SC2 Tools`. The tag receives the title before config and on navigation. Custom events supply it directly so callers cannot override it.

**Measured.** The loopback X1 probe captured synthetic record titles on 16 of 20 baseline hits. Automatic events inherited a fixed title. Omitting it kept the previous template, undefined read stale browser metadata, and null or empty produced a blank title. The explicit site label safely reset all five destination hits.

**Verification.** 180 tests across eight Vitest files, TypeScript, scoped ESLint, 25 UI lint rules and UI lint passed. Seven preflight-validated mutations failed their intended assertions. Restored source bytes matched their original hashes.

**Browser.** Chromium captured 69 hits across all nine record templates, a public player and a static route, including 47 automatic events. Zero raw titles, missing titles or escaped requests. The signed-out build queued the fixed title before tag config after consent. Browser tabs keep their visible titles.

**Build.** The production build passed. Windows still reports the two inherited overages: overlay 241,222 B (+3 B versus M1) and dock 225,393 B (-5 B). Guide builds are at 174,359 of 175,000 B. ADR 0076 records the title policy.

**Owner action.** Switch off Form interactions and Site search in Google Analytics Enhanced measurement. The offline container still emitted form and site-search events with synthetic data.

**Not verified.** Production traffic to the analytics property. X6 and X7 are separate slices. Ledger: none.
