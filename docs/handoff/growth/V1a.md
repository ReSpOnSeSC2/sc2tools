# V1a: agent interface refresh, part 1 (tokens, base style, window shell)

**Shipped.** Desktop agent 0.25.0 (version set by R1, not published). One token set in `ui/theme.py` (colour, type, spacing, radius, elevation, motion) builds the whole application style sheet. The main window's frame, navigation, page header and Dashboard are flat: dark surfaces told apart by tone, one type scale in the system font, one style for every stock control, and the page's main action as its only filled button. Each skin has one accent (Default violet, Protoss gold, Terran steel blue, Zerg orange), a small painted race mark beside the name (`ui/brand_mark.py`) and the race border artwork it already had. The border animation lasts 0.3 s and is skipped while Windows has animation effects off (`ui/system_motion.py`). `apps/agent/tests/manual/interface_gallery.py` renders every main surface in the four skins at two sizes.

- **What dated the look (gallery on the base commit).** A purple gradient bezel around a bordered sidebar and a bordered page, each holding bordered cards; every button filled and outlined alike; race skins that put a race-coloured frame on every card and button but kept the default purple on the selected page, scroll bars and headings, and lost the status-light colours; letter-spaced capitals and two type sizes; the stock Qt menu wedge on **Agent** and squeezed square help buttons.
- **Decisions (ADR 0078).** Surfaces and text are shared; a skin is its canvas tint, one accent family and the focus ring. `theme.skin_layer` is the colour-only difference from the default, so appending it never moves a widget. "The first page" is the Dashboard: the window's first page and the one an unpaired player opens on (Companion is V1c). Geometry is unchanged (frame margins 10 and 14, sidebar 240, window buttons 26 x 24), so nothing reflows. Status colours stay in `palette.py` (the tray icon draws them with PIL) and `theme.py` re-exports them. The selected tint is 14% so every status colour reads at 4.5:1 on a selected row in every skin. Companion keeps `CONSOLE_GRADIENT` and its own style sheets until V1c; `css_for_skin` still recolours its accents in race skins.
- **Bugs fixed on the way.** Status dots lost their colour in race skins (rules appended to a bare `color:` style did not parse). Help buttons were squeezed to 20 x 17 by `min-height: 0`.
