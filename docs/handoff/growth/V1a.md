# V1a: agent interface refresh, part 1 (tokens, base style, window shell)

**Shipped (PR stacked on 883).** Desktop agent 0.25.0 (version set by R1, not published). One token set in `ui/theme.py` (colour, type, spacing, radius, elevation, motion) builds the whole application style sheet. The main window's frame, navigation, page header and Dashboard are flat: dark surfaces told apart by tone, one type scale in the system font, one style for every stock control, and the page's main action as its only filled button. Each skin has one accent (Default violet, Protoss gold, Terran steel blue, Zerg orange), a small painted race mark (`ui/brand_mark.py`) and the race border artwork it already had. The border animation lasts 0.3 s and is skipped while Windows has animation effects off (`ui/system_motion.py`). `apps/agent/tests/manual/interface_gallery.py` renders every main surface, plus the Dashboard needing attention and waiting to be linked, in the four skins at two sizes.

- **What dated the look (gallery on the base commit).** A purple gradient bezel around a bordered sidebar and a bordered page, each holding bordered cards; every button filled and outlined alike; race skins that framed every card and button in the race colour but kept the default purple on the selected page and scroll bars, and lost the status-light colours; letter-spaced capitals and two type sizes; the stock Qt menu wedge on **Agent**, squeezed square help buttons, and "Help & support" drawn as "Help  support".
- **Decisions (ADR 0078).** Surfaces and text are shared; a skin is its canvas tint, one accent family and the focus ring. `theme.skin_layer` is the colour-only difference from the default, so appending it never moves a widget. "The first page" is the Dashboard (Companion is V1c). Geometry is unchanged (frame margins 10 and 14, sidebar 240, window buttons 26 x 24). Old token names keep new meanings: `BORDER_STRONG` is a quiet divider, `BUTTON_CHECKED` the 14% selected tint; a field outline takes `BORDER_CONTROL` and a filled action `ACCENT` with `ON_ACCENT`. Status colours stay in `palette.py` (the tray draws them with PIL).
- **Review (7 findings, 6 fixed).** A race skin no longer fails to build when the install folder holds a brace (`theme._rules` keeps a quoted `url()` whole). Danger buttons show the focus ring. The gallery adds the two Dashboard states and saves each picture once its layout settles (the first pictures caught half-done layouts at the minimum size). The token guard also catches `QFont(..., 11)`, `Qt.GlobalColor.*` and named colours in style strings. The check-in cards' Confirm is filled again and their fields, and Companion's, are outlined at 3:1. The Dashboard's counts share one line, View problems is a full-width row at the foot of its card with left-aligned text, and the update card has its neighbours' inset. Not fixed: the Activity log and Recent games pages still clip at 480 x 360 as before V1a; they are V1b's pages.
- **Also fixed.** Status dots lost their colour in race skins; help buttons were squeezed to 20 x 17; four labels with an "&" drew a gap (Help & support, Border & animations, Help & troubleshooting, Save title & description).
