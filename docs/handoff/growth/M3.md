# M3 · Neutral Match Room OBS source

- **Built.** The host can copy an OBS Browser Source URL with optional credit. The transparent source shows the veto board before play and a compact score panel during and after the series.
- **Privacy.** The source accepts only a watch locator in the fragment. It shows neutral seats and known ladder titles or numbered maps. Player names, custom map labels and replay details stay off the broadcast. Encoded aliases redirect with private headers, and the source skips indexing, analytics, error reporting and service-worker interception.
- **Consistency.** Revision-aware polling runs every five seconds while visible and slows when hidden. Disconnects hide the last frame. Deletion or expiry ends polling.
- **Checks.** 469 focused tests in 43 suites passed, with follow-up theme and legacy overlay scopes, TypeScript, changed-file lint and complexity, 25 UI rules and UI lint. Eight preflight-validated mutations failed their intended assertions and restored the original bytes.
- **Build.** The static OBS route uses 172,277 of 175,000 gzip bytes. The existing overlay measured 241,139 bytes on Windows after loading its recovery card on demand, down 299 bytes from the prior M3 build. The exact M2 in-worktree log recorded 241.2 kB against 240 kB. A fresh M2 archive build used 240,374 bytes with different chunk output. Hosted Linux runs the unchanged budget.
- **Browser.** Checked signed out at 360, 768 and 1280 px, both incoming theme preferences, 800 × 600 with all twenty maps, and touch copy and retry at 360 px.
