# N6 · Discord build guide command

- **Built.** The signed Discord `/build` command returns a private reply with up to five published 12-worker ladder openers for one of nine matchups. It uses only a warmed public aggregate cache and never stores interaction data.
- **Availability.** A warming, empty or expired cache links to the matchup guide. When guides are disabled, the command explains that they are unavailable. The registration script previews offline and applies only on explicit request.
- **Gates.** 150 API tests across six suites and 63 web tests across eight files passed, with both type checks, scoped lint and complexity, help indexing, all 25 UI rules, UI lint and eight exact mutations. Source hashes matched after restoration.
- **Build and browser.** The production build prerendered the public help article. Six signed-out Chromium cases covered light and dark at 360, 768 and 1280 px with no Discord requests and no serious or critical axe findings. The help route measured 185,970 of 200,000 gzip bytes. The inherited Windows overlay overage fell by 4 bytes.
- **Blocked on owner Discord application setup.** Configure and verify the deployed endpoint and a guild install before registering the command and publishing the install link. Live Discord, deployment and production aggregate availability were outside local proof.
