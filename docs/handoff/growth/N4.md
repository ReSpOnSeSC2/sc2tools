# N4 · Weekly report tray reminders

- **Shipped.** Agent Settings adds a separate, default-off weekly report reminder. The tray uses fixed text and points to the private Notifications inbox.
- **Delivery.** The linked Agent checks one unread weekly row on socket connect, a weekly bell signal, or opt-in. It checks again when a match interrupts delivery and stores the latest delivered ISO week under a hashed owner key.
- **Review.** A clean interruption releases an unsent receipt and preserves earlier receipts. A report read during the match stays quiet.
- **Verification.** 215 focused Agent tests across eight separate processes, eight changed Python AST checks and diff check passed. All nine preflight-validated mutations failed their intended assertions with source hashes restored.
- **Pictures.** Inspected offscreen checked and unchecked settings in all four skins at 480 × 360 and 1100 × 760.
- **Web compatibility.** The public changelog skips one leading draft section and validates every release. The static page and both RSS feeds exclude the weekly reminder draft. 31 focused Vitest tests, TypeScript, scoped ESLint, 25 UI rules, UI lint, the Next build and nine signed-out Chromium cases passed.
- **Unverified.** Native tray display, installed Agent, actual gameplay and production report delivery. A crash between receipt persistence and dispatch can miss a reminder. The report remains in the private bell.
