# N2 Desktop game milestone notices

**Shipped.** Players can opt in to unread game milestone notices next to Desktop notifications. The Agent reads the private bell with the linked device credential and holds the notice until play ends.

**Delivery.** Consecutive matching reads give the bell time to settle. A later row can still arrive after the quiet interval and remains in the bell. Same-account relinks fence retired uploads. A hashed owner-and-game receipt is saved before dispatch, so a crash between those steps can miss one toast.

**Checks.** 417 focused Agent tests passed in 16 separate processes, including the four review regressions. Nine exact mutations failed on their intended assertions and all source bytes were restored. Syntax and diff checks passed.

**Pictures.** Inert Qt Settings sheets covered all four skins at 480 × 360 and 1100 × 760. The control stayed in view with no horizontal scroll. Tab focus, Space, Save and reload passed.

**Not verified.** Native Windows toast display, the installed Agent and real StarCraft matches.

**Follow-up.** The owner builds, verifies and publishes the Agent. Both changelogs target the draft 0.25.1 release. Ledger U5 and [ADR 0051](../../adr/0051-game-moment-alerts.md).
