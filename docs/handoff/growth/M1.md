# M1 · Match Rooms veto

- **Built.** Hosts can open a best-of room, invite both seats and spectators, run a timed map veto, record manual scores, and share a neutral result as text or PNG. Practice rooms support one player.
- **Privacy.** Credentials stay in link fragments and the room route is noindex, uncached, and excluded from analytics and browser error reporting. The API redacts the locator from logs. Exports omit names, custom map labels, and room links.
- **Consistency.** Mongo enforces one active slot per room and a 14-day TTL. Writes carry the revision the player saw. A lost creation response can recover the same invite, and host deletion erases room data immediately. A digest-only marker blocks delayed retries for ten minutes.
