# X6 · Cross-tab analytics consent

**Shipped.** AppShell keeps one shared consent listener active, including on the signed-out status page. Open tabs apply the latest stored choice and update a loaded tag on both revocation and regrant.

**Decisions.** A regrant sets the normalized page state before granting consent on tracked routes. Untracked routes keep the opt-out flag. Clearing or corrupting the saved choice disables tracking, and revocation clears analytics cookies before subscribers run.

**Verification.** 216 focused Vitest tests across 12 files, TypeScript, scoped ESLint, 25 UI lint rules, UI lint and diff checks passed. Nine preflight-validated mutations failed their intended assertions. The runner restored and hash-verified the source bytes.

**Browser.** Two signed-out Chromium tabs exercised seven native storage changes across /status, /guides and /match/room, with exactly one update per change and zero collection attempts. A fresh status tab requested zero tag scripts.

**Build.** The production build passed. Exact-base Windows overlay stayed at 241,222 B and dock fell 1 B to 225,392 B. These two local overages also appeared on X5. The guide build route measured 174,429 of 175,000 B.

**Follow-up.** ADR 0076 records consent ordering. Hosted checks and production analytics collection are outside the local proof. X7 handles the opponent-search parameter. Ledger: none.
