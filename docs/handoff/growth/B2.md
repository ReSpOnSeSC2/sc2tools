# B2 · Balance claim builder and receipt

- **Built.** `/balance/claim` checks an advantage using same-tier games and gives a receipt with sample size, a Wilson interval and a link pinned to its season and snapshot date. All-map claims use 95% intervals and map-specific claims use 99%. Matchup and league pages link directly to receipts. PNG downloads carry SC2Pulse credit.
- **History.** The evidence API reads the active snapshot or the exact archive for the requested date. Dates superseded before receipt retention began are unavailable. [ADR 0082](../../adr/0082-ladder-balance-snapshot.md)
