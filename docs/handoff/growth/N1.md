# N1 Private ladder milestones

**Shipped.** Players can opt in to Milestones under Settings → Preferences and find seven kinds of qualifying ladder moments in the private bell and inbox. Fresh competitive replays in the same batch can each generate bell rows. The latest fresh replay drives the overlay.

**Decisions.** Consent defaults off, per-kind mutes apply and shared sockets receive only a refresh. League changes and streamer-opponent wins stay on the overlay. Giant-killer gaps are rounded to 100 MMR. The existing owner/game receipt keeps pending bell items and a fresh reupload can finish a failed write without replaying overlay delivery. ADR 0051 records the policy.

**Verification.** API 124 tests across 12 suites, web 78 across six files, API and web TypeScript, changed-file ESLint, UI lint and 25 UI-rule tests passed. Ten validated mutations were killed. Production Next.js built 197 static pages. The protected inbox uses 181,706 gzip bytes within its 520,000-byte budget. The Windows dock and overlay budget check still reports inherited overages, up 2 and 4 bytes respectively from exact S2. Signed-out public help returned 200 and the inbox redirected to sign-in (307) without notification rows. All six Chromium viewport/theme fixtures passed and were inspected.

**Not verified.** Live production accounts and OBS delivery were outside the local fixture.
