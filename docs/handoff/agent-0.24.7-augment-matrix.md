## Corrections to the drafted steps

The sizers' drafted steps were checked against the source; these changed.

- **18.1** Added a missing precondition. Auto-update is on by default. A running 0.24.6 installs by itself after 2 idle minutes with no OBS output, no match and no capture. It checks the feed at startup and every 12 h. So check the version before anything else. OBS outputs are read through the saved OBS WebSocket settings. A refused connection counts as no live output, so the update can go ahead. Any other error, such as a wrong password, counts as live, so the update waits indefinitely.
- **18.2** 'Will install after this match' is the single message for every safety hold. It appears during a match, for about 140 s after a match (20 s settle plus 2 idle minutes), while any OBS output is active (stream, recording, virtual camera, replay buffer or an unknown state), while a replay capture or engine rebuild runs, and for the first 2 minutes after the app starts.
