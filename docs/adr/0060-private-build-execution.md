# ADR0060: Private build execution evidence

One owner-only `/v1/games/:id/build-execution` resource feeds the rule card,
timeline and rail percentage. No coach, review, public or overlay adapter
exposes it. The applied confirmed build wins, otherwise the detected identity.
Exact owner custom slugs resolve current rules. Missing or opponent-side
definitions never fall back by name. Catalog/zero-rule builds have no grade.

Detailed evaluation shares the existing token, prerequisite, hallucination and
proxy predicates and strict-before deadlines. Existing classifier callers are
unchanged. Positive minima seek the required event, excesses the first forbidden
event. Absence/shortfall/upper-bound success are labelled deadline evidence.
Unknown evidence never becomes a failure. Any unknown rule withholds the overall
percentage; otherwise its denominator is all saved rules.

One sequential max25 dossier hydration supplies all timing rows. An extra tiny
town-hall line preserves the natural after the starting base. Existing DNA
medians and the current parser retain era-aware start clocks. Catalog samples
exclude custom provenance; custom samples use exact owner slugs. Both private
adapters require three observations; public/Community/benchmark floors stay intact.

Limits: 200 game results, 100 compact scalar baselines, four in-flight work items,
five-minute TTL. Keys include owner epoch, game/reparse metadata, effective build
and rules hash. Owner existence precedes cache access; final owner/epoch/row
checks reject stale completions. Detail replacement, ingest/quarantine, definition,
reclassification, check-in and visibility changes retire caches. No persistent
cache writes, infrastructure, job, index or migration is added.

Practice uses the existing explicit Ghost action. Deploy API before web;
reverting API/web requires no stored-data conversion.
